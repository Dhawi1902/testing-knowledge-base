Monitoring

How a team watches its systems every day, and how a tester watches the server while a load test runs. Concepts first, then one shared setup of Grafana, Alloy, Prometheus and Loki next to the Playground, then each use hands-on.

Important: This module is in progress, written against Grafana 13.2.3, Alloy v1.20.1, Prometheus v3.15.0, Loki 3.7.8 and k6 v2.2.0. Every config file lives in monitoring/sample/.
