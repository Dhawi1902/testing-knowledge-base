Playground

The Pizza Playground is the app every hands-on track in this knowledge base points at. It is a small online pizza shop: browse a menu, build a pizza, check out, pay through a mock payment gateway, and watch the order move across a kitchen board. It runs on your own machine with one Docker command, comes seeded with data, and resets to a clean state with one API call.

There are two ways to use it:

WhereUse it for
Hostedpizzaplayground.deta.myClicking around, Playwright scripts, API exploration, recording a first script
LocalYour own machine, see Run It LocallyLoad tests, anything that resets data, anything you want to break

Important: the hosted copy is one small shared server. A load test against it slows it down for everyone, and a reset wipes everyone's orders. Run load tests and resets against your local copy.

The playground is a separate repository, not part of these docs. Repository: github.com/syamilu/pizza-playground (public GitHub, no sign-in needed).
