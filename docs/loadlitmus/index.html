LoadLitmus

LoadLitmus is the dashboard we run our performance tests from. It wraps JMeter in a browser UI: pick a plan, set the load, press play, watch the log stream, and keep every run's results in one place per project. It runs on your own machine or a test server — no cloud, no database, all data stays local.

Important: this track is written against LoadLitmus 1.4.5 with JMeter 5.6.3, and covers the parts we use on real engagements. Everything in the Status table below was exercised on a live instance while writing; anything not exercised says so.
